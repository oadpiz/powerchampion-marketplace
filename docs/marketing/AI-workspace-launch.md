## Customer-facing data explanation

**English**

Chat messages and the API key you enter stay in page memory and are sent through the application to the model gateway when you submit a request. They are not saved as account chat history. Agent drafts are saved in your browser only when you choose Save draft; opening a test copies the configuration to temporary tab storage for loading within 30 minutes. See the privacy notice for saved drafts, account records, and optional public-trial data handling.

**繁體中文**

對話與你輸入的 API 金鑰留在頁面記憶體；送出請求時，會經由應用程式轉送到模型閘道，不會存成帳號對話歷史。智能體草稿僅在你選擇儲存時留在瀏覽器；開啟測試則會把設定複製到分頁暫存，供 30 分鐘內載入。已存草稿、帳號紀錄與選用公開試用的處理方式，請參閱隱私權說明。

## Release facts to retain in edits

- Pre-written examples are clearly labelled and do not demonstrate a live model response.
- Trial access requires operator enablement, a configured server-side trial key, and a positive global daily request cap. Per-session and global allowances apply; this is not unlimited access.
- The current assistant templates have no connected browsing, email, private databases, or tool execution.
- Saving an agent draft stores its reference text on that browser. A test transfer expires for reloading after 30 minutes; this does not automatically erase an already open chat or every browser copy.
- The account portal records manual credit requests. Approval is not a card payment and does not automatically add gateway funds.
- Dedicated GPU and custom integration service details need a project-specific discussion; do not add delivery dates, hardware availability, customer counts, or performance guarantees without evidence.
- Use the actual released language routes. The root workspace and agent tools currently offer English and Traditional Chinese; do not imply that every tool has been translated into every public marketing-page language.
