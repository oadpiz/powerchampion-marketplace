**Primary outcome:** a qualified API or infrastructure inquiry containing an identifiable use case and a way to respond. A page visit, generated code snippet, or API-key dialog open is an intermediate action, not a new customer.

**Measurement notes:** Record the date range, channel, creative language, destination, visits, meaningful tool interactions, inquiries, and verified customer outcomes. Keep raw counts beside rates. An access-request completion rate uses completed requests divided by the relevant eligible sessions; exclude internal QA when possible. If tracking is not installed, label the metrics unavailable and begin with existing channel click data and manually recorded inbound inquiries. UTM parameters alone do not install analytics or produce a report.
